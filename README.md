# playbox-timer

Playbox Timer — React single-page app for PlayStation rental billing & timers.  
Features: multi-user admin, per-unit timers, loud alarms at 10 minutes & time-up, bookkeeping logs, export CSV, dark/light mode.

## Run locally
```bash
npm install
npm start
```

## Build
```bash
npm run build
```

## Deploy
Deploy to Vercel (recommended). This repo includes `vercel.json` to use `--legacy-peer-deps` for install.
